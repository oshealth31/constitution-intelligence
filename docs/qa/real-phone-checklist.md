# Real-phone checklist (task T4)

Automated tests run in emulated phones (an iPhone in Safari's engine and an Android phone in
Chrome). This checklist is for a **real** phone, held by a person. It takes about 20 minutes.
Do it on one Android phone and, if you can, one iPhone. Use the **pilot or staging site with
fictional data**, never a live organisation's real account.

Write down for each step: ✅ worked, ⚠️ worked but awkward (say what), or ❌ failed (say what you
saw, and take a screenshot).

## Before you start

| Item               | Android               | iPhone                |
| ------------------ | --------------------- | --------------------- |
| Phone model        |                       |                       |
| System version     | (Settings → About)    | (Settings → General)  |
| Browser + version  | Chrome …              | Safari …              |
| Network            | Wi-Fi / mobile data   | Wi-Fi / mobile data   |
| Date and tester    |                       |                       |

## Steps

| #   | Do this                                                                                                   | Expect                                                                       | Android | iPhone |
| --- | --------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- | ------- | ------ |
| 1   | Open the portal address (for example `/o/sample-community-choir`)                                          | The organisation's name, logo and colours; nothing cut off at the sides       |         |        |
| 2   | Sign in as a member. Tap the button straight away after typing                                            | You are signed in. The password never appears in the address bar               |         |        |
| 3   | Turn the phone sideways and back                                                                          | The page re-arranges; nothing overlaps                                         |         |        |
| 4   | Open **Read**, open the constitution, use the contents to jump to a clause                                | The clause is shown; text is easy to read without zooming                      |         |        |
| 5   | Pinch to zoom in on text, then back out                                                                   | Zoom works (it is not blocked)                                                 |         |        |
| 6   | **Search** for a word that appears in the constitution (for example "quorum")                             | Matching clauses, with the word highlighted                                   |         |        |
| 7   | Open **Find clauses** / **Ask**, type a question                                                          | Matching clauses (or an answer) with the clause numbers                        |         |        |
| 8   | On the home page, tap **Save for offline reading**                                                         | "Saved. You can now read the constitution without the internet."             |         |        |
| 9   | Turn on **flight mode**. Open the portal address again                                                    | The saved copy opens, marked "Offline", with the last synchronisation time     |         |        |
| 10  | While offline: jump to a clause and search the saved copy                                                 | Both work                                                                      |         |        |
| 11  | Turn flight mode off                                                                                      | It shows "Online" and checks the saved copy is up to date                      |         |        |
| 12  | iPhone only: **Share → Add to Home Screen**, open it from the home screen, repeat steps 9–11              | Works the same from the home-screen icon                                       | n/a     |        |
| 13  | Android only: Chrome menu → **Add to Home screen / Install**, open it, repeat steps 9–11                  | Works the same from the home-screen icon                                       |         | n/a    |
| 14  | **My profile → Sign out**                                                                                 | Signed out; the saved copy is removed from the phone                          |         |        |
| 15  | Sign in as the organisation **administrator**; open **Manage**, upload a small PDF from the phone's files | The upload works; the version appears for review                               |         |        |
| 16  | Turn on two-step sign-in on the profile (authenticator app on the same phone), sign out, sign in again    | The code is asked for and accepted                                            |         |        |
| 17  | Make the system text size bigger (Settings → Display/Accessibility), reload                               | Text grows; buttons and menus still usable                                    |         |        |
| 18  | Dark mode on (if the phone has it), reload                                                                | Still readable (the site stays light; that is expected)                        |         |        |
